🗺️ Что такое Grad-CAM (SOTA метод объяснимости)

Gradient-weighted Class Activation Mapping (Grad-CAM) — современный метод визуальной интерпретации нейросетей (Selvaraju et al., ICCV 2017). Метод вычисляет важность каждого пикселя для предсказания через градиенты потока ошибки к последнему сверточному слою.

Математически: веса α_k = (1/Z) ΣΣ ∂y^c/∂A^k_{ij}, тепловая карта L^c_GradCAM = ReLU(Σ_k α_k · A^k). Где A^k — активации k-го канала, y^c — оценка класса c.

В данном проекте Grad-CAM применяется к последнему сверточному блоку обеих моделей. Тёплые цвета (красный/жёлтый) = высокая важность для классификации. Холодные (синий) = низкая важность.
